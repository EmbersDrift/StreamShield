# v1.1.3 人工验收清单

## 范围与放行条件

目标：Minecraft 1.21.11 / 26.1.2 × Fabric / NeoForge；Windows + OBS **游戏采集**。不保证窗口采集、桌面采集、系统输入法窗口或外部日志编辑器。

代码单测、构建及启动检查不等于 OBS 输出验证。以下项目默认均为**待人工检测**。配置中放入虚构敏感内容，如 `TEST-SECRET-123` 和 `example.invalid`，先本地录制，不要直接直播试验。任意一次泄露私密配置即判定未通过，暂勿发布。

## 入口

- F8 打开设置 → 通用 → 隐私工具箱：计分板助手、自检、导入导出。
- 配置页保护在受支持的 Windows 环境默认开启。游戏采集显示纯色遮罩；本机界面通过 Overlay 显示。
- 关闭界面不会自动恢复。回到游戏按 F9，或点击配置页“关闭私密界面并恢复采集”，确认后恢复。确认后额外保留几个受保护帧。
- F9 为默认紧急遮罩键，可在按键绑定中修改；按键测试在没有其他界面打开且游戏获得焦点时进行。
- 服务器方案、物品提示净化、容器标题净化和书本阅读净化默认关闭，分别开启测试。

## A. 配置保护：必须逐帧检查录制

- [ ] 四种版本/加载器分别通过 F8、Mod Menu 或 NeoForge 配置入口打开。自己能读写设置，OBS 只有纯色，不含屏蔽词、玩家名、字体预览。
- [ ] 放慢或逐帧查看打开配置的第一帧、关闭的最后一帧，均无私密界面残留。
- [ ] 测试规则子目录、工具箱、保存/取消确认、导入/导出确认、直播前检查页面。整个会话持续保护。
- [ ] 在配置里输入、选中、复制虚构敏感词，悬停工具提示、滚动、打开字体字形预览；采集无内容泄露。
- [ ] ESC/完成离开界面后遮罩仍在；F9 确认恢复才显示游戏。取消恢复仍保持遮罩。
- [ ] 在恢复等待期间重新打开设置，遮罩不提前解除。
- [ ] 测试全屏切换、窗口缩放、GUI 比例调整、切出再切回、资源重载；无闪现、崩溃、旧字体残影。
- [ ] OBS 先开/后开、采集源停用再启用两种次序都测试；分别检查游戏采集的叠加层捕获选项。以录像结果为准，不因 Overlay 显示 READY 就视为通过。
- [ ] 在独立测试配置中模拟 Overlay 不可用/初始化失败。私密界面不能回落到采集画面；只可出现不含敏感内容的恢复提示。重试保持遮罩；关闭会话不返回旧配置页。
- [ ] 保底失败状态下关闭会话，能回到游戏，不会永久卡黑；后续可重新尝试打开设置。

## B. 紧急遮罩

- [ ] 游戏内按 F9 立即进入纯色采集状态，再按 F9 请求确认恢复。取消继续遮罩，确认恢复游戏。
- [ ] 修改快捷键并重启游戏，绑定保留；不触发聊天发送、丢物品等其他操作。
- [ ] 屏幕测试图标、HUD 隐藏、碰撞箱隐藏原有功能仍正常；紧急遮罩不是暂停服务器。

## C. 计分板助手及字形

- [ ] 进入有计分板的服务器，打开工具箱能看到样本；无需开启敏感诊断日志。默认日志不出现原文。
- [ ] 点选整行或字形样本，替换内容留空后添加；计分板总开关开启时生效，关闭时不生效。
- [ ] 多色逐字 IP、资源包私用区字形、同码点不同字体分别验证；字体限定规则只命中指定字体。
- [ ] 编辑替换内容后保存；退出/重进仍存在，可在配置中移动、禁用和删除。
- [ ] 超大字形不会盖住按钮，缺失字体显示方框不崩溃。未被替换的颜色、图标保留。
- [ ] 清空样本及换服/断线后，旧服务器样本不再保留（仍在服务器时渲染会重新采集）。

## D. 按服务器方案

- [ ] 开启“按服务器切换隐私方案”，A 服添加仅 A 服规则；B 服添加另一规则；往返自动选择各自规则。
- [ ] 首次访问继承全局值；退出服务器恢复全局；重启后 A/B 规则各自保留。
- [ ] 配置文件位于 `config/streamshield/profiles/<地址哈希>.json`，文件名不含明文地址。内容中的匹配词仍可能敏感。
- [ ] 配置会话中不覆盖未保存输入；结束会话并恢复采集前完成待处理方案切换。
- [ ] 全局 `live_hider.json` 不被 A/B 服规则污染；全局保护开关、诊断、皮肤来源保持全局，不随方案变化。
- [ ] 关闭服务器方案恢复全局。单机不按服务器地址分组。
- [ ] 仅在测试副本中使用错误 JSON 或只读目录：切换失败进入遮罩并显示工具箱错误状态，不崩溃、不每帧刷日志。修复后重试，或离服/关闭该功能后能恢复。
- [ ] 启用服务器方案时，外部编辑全局配置不会热重载覆盖当前方案；需要结束服务器方案会话后重新加载。

## E. 导入、导出、自检

- [ ] 导出前出现敏感信息警告；输出位于 `config/streamshield/exports/`，不会覆盖旧导出。
- [ ] 导出包含允许的文字/HUD选项，不含皮肤本地路径、凭据、诊断和配置保护开关。分享前人工检查屏蔽词/IP。
- [ ] 将有效文件放入 `config/streamshield/import.json`，确认导入后生效；旧设置备份在 `backups/`。
- [ ] 返回配置页不会用旧控件值覆盖导入；取消导入无变化。
- [ ] 错误格式、未知 schema、超过1MiB文件被拒绝，原设置保留，无敏感内容写进报错日志。
- [ ] 自检中的通用文字、自身名字、计分板、告示牌及额外文字示例与开关相符。它只是样例，不代替实际TAB/聊天/告示牌测试。

## F. 其他文字界面与回归

- [ ] 物品描述中放测试屏蔽词；打开净化仅影响显示。关闭恢复；物品归一化和资源包名称仍正确。
- [ ] 带测试文字的容器标题可净化；容器操作、物品数据不变。
- [ ] 阅读书本时净化生效；关闭恢复。编辑、签名、发送内容不被修改。换行或复杂样式分隔的词可能需要额外规则，需专门验证。
- [ ] 自己/其他玩家匿名两个主开关及聊天输入净化不倒退；不开启不分配随机ID。
- [ ] 告示牌所有变种、TAB、聊天、计分板、HUD及碰撞箱既有功能回归；物品栏/ESC内不出现碰撞箱残留。
- [ ] 最后安装 Sodium、Replay 等实际使用组合复测启动和上述 A 项，保存仅含虚构测试信息的录制。
